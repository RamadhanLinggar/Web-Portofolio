About Project

Tentang Project

CineFinder merupakan website pencarian dan eksplorasi film yang dikembangkan sebagai personal project untuk mempelajari dan menerapkan React.js dalam pengembangan aplikasi web.

Website ini menggunakan TMDB REST API untuk mengambil dan menampilkan informasi film. Pengguna dapat mencari film, melihat daftar film populer, memfilter film berdasarkan genre, serta melihat informasi detail dari film yang dipilih.

CineFinder juga menyediakan halaman detail film yang dilengkapi informasi seperti sinopsis, rating, tanggal rilis, dan trailer. Fitur favorites menggunakan localStorage sehingga film yang dipilih pengguna dapat disimpan pada browser.

Project ini juga menggunakan React Router untuk mengatur navigasi antar halaman serta Tailwind CSS untuk membangun tampilan antarmuka yang responsif.

Features

Fitur Utama

Pencarian Film

Memungkinkan pengguna mencari film berdasarkan judul dan menampilkan hasil pencarian dari TMDB API.

Filter Genre

Pengguna dapat memfilter daftar film berdasarkan genre untuk mempermudah menemukan film yang diinginkan.

Detail & Trailer

Menampilkan informasi detail film serta trailer yang tersedia melalui data dari TMDB.

Favorites

Pengguna dapat menyimpan film favorit dan mengaksesnya kembali melalui halaman Favorites.

Responsive Design

Tampilan dirancang agar dapat digunakan dengan baik pada berbagai ukuran perangkat.

REST API Integration

Mengambil dan mengolah data film secara dinamis menggunakan TMDB REST API.
