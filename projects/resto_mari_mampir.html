Tentang Project

Resto Mari Mampir

Resto Mari Mampir merupakan website restoran yang dibuat sebagai personal project untuk mengembangkan kemampuan dalam membangun website.

Website ini menampilkan informasi restoran dan menyediakan tampilan antarmuka yang dirancang agar pengunjung dapat melihat informasi yang tersedia dengan mudah.

Dalam proses pembuatannya, project ini menggunakan HTML dan CSS untuk membangun struktur serta tampilan, JavaScript untuk interaksi pada halaman, dan PHP untuk bagian backend.
